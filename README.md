# ATMOS — Weather Dashboard 🌦️

A modern, responsive weather dashboard built with HTML, CSS, and JavaScript.
ATMOS retrieves real-time weather information and five-day forecasts using
the Open-Meteo API.

## Overview

ATMOS provides a clean, minimalist interface for checking weather conditions
across different cities. The design combines professional styling with a
premium visual identity.

## Features

- Search for cities around the world
- Display current weather conditions
- Show current temperature and feels-like temperature
- Display humidity and wind speed
- Display the UV index
- View a five-day weather forecast
- Show loading and error messages
- Responsive layout for different screen sizes

## Technologies Used

- HTML5 — page structure
- CSS3 — styling and responsive layout
- JavaScript — application logic and API integration
- Open-Meteo API — weather data
- Open-Meteo Geocoding API — city searches
- Visual Studio Code — development environment
- Git and GitHub — version control and project hosting

## How It Works

1. The user enters a city name.
2. The Geocoding API finds the city's coordinates.
3. The application requests weather data for those coordinates.
4. JavaScript updates the dashboard with the retrieved information.
